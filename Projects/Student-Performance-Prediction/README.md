# Student Performance Prediction

## Objective

The objective of this project is to build a Machine Learning model
that predicts student performance based on different academic and
personal factors.

## Input Features

The model may use features such as:

- Study hours
- Attendance
- Previous exam scores
- Assignment scores
- Sleep hours
- Participation in activities

## Output

The model will predict the student's performance based on the
provided input features.

## Tools and Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook
- Matplotlib

- Improve model accuracy

- Perform feature engineering
